# Browser Project

**Кроссплатформенный браузер на Electron** — итоговый проект по информатике, 10 класс.

Собственный Chrome UI в стиле Safari, вкладки с drag & drop, закладки с папками и bulk-операциями, история, загрузки, cookie-менеджер, приватный режим, режим чтения, PDF-viewer, блокировка трекеров. Все данные хранятся **только локально** на устройстве пользователя.

---

## ✨ Возможности

**Интерфейс**
- Chrome UI в стиле Safari с капсулой навигации `‹ ∣ ›`
- Адресная строка с автодетектом URL и поискового запроса
- **Omnibox dropdown** — поиск по закладкам и истории прямо из адресной строки
- Индикатор безопасности соединения (HTTPS / HTTP / внутренняя страница)
- **Индикатор блокировки трекеров** — счётчик заблокированных запросов на текущей странице
- Панель закладок с папками
- Status bar с URL при наведении на ссылку
- Светлая / тёмная / системная тема + 6 акцентных цветов
- **Кастомная тема из JSON-файла** — пользователь загружает свои цвета
- Кастомные tooltips для иконок
- **Кастомизация тулбара**: включение/отключение кнопок и изменение их порядка

**Вкладки**
- Создание, закрытие, восстановление закрытых, дублирование
- **Drag & drop** — перетаскивание вкладок для изменения порядка
- **Горячие клавиши переключения**: `Cmd+1..9`, `Cmd+Opt+←/→`, `Ctrl+Tab`
- **Контекстное меню вкладки**: «Дублировать», «Закрыть», «Закрыть другие», «Закрыть вправо»
- **«Недавно закрытые» в меню** (до 25, хранится только в RAM)
- Favicon, заголовок, индикатор загрузки, плавные анимации
- Приватные вкладки (инкогнито) с отдельной сессией
- LRU-выгрузка неактивных вкладок для экономии памяти (макс. 10 одновременно)

**Данные**
- Закладки с папками, менеджер, импорт/экспорт в HTML (совместим с Chrome/Firefox)
- **Bulk-операции с закладками**: выделение нескольких, массовое удаление, перемещение
- История с группировкой по датам, поиском, автоочисткой через 90 дней
- **Экспорт истории в JSON / CSV** (для Excel, с BOM-маркером UTF-8)
- Загрузки с прогресс-баром, иконками по типу файла, счётчиком активных
- Cookie-менеджер: просмотр, создание, редактирование, удаление, очистка всех данных сайтов
- Восстановление сессии при перезапуске

**Стартовая страница**
- Собственный набор ярлыков на localStorage
- **Drag & drop** ярлыков для изменения порядка
- `Cmd/Ctrl+клик` или средняя кнопка мыши — открыть в новой вкладке
- Кастомные tooltips

**PDF-viewer**
- Собственный просмотрщик на **pdfjs-dist** (не встроенный Chromium)
- Панель инструментов: навигация по страницам, масштаб, «по ширине», поворот на 90°
- **Поиск по тексту** с подсветкой и навигацией (`Cmd+F`)
- **Миниатюры страниц** в боковой панели
- **Запоминание последней страницы** (по имени файла)
- Ленивый рендер, Retina-качество
- **Drag & drop PDF-файлов** прямо в окно

**Безопасность и приватность**
- Кастомные диалоги разрешений (камера, микрофон, геолокация)
- Warning-страница для HTTP-сайтов
- Error-страница для сетевых ошибок и проблем с сертификатами
- Блокировка трекеров и рекламы (200+ доменов)
- **HTTPS-only режим** — блокирует все незащищённые сайты
- **Referrer Policy** — обрезает заголовок `Referer` до origin (без пути и query)
- **Защита от WebRTC IP leak** — сайты видят только публичный IP
- **Блокировка `data:` в mainFrame** на уровне сессии
- **Гарантированная очистка приватной сессии** при выходе (двойная)
- **Ограничение размера кэша Chromium** до 100 МБ + кнопка ручной очистки
- CSP во всех внутренних HTML

**Настройки**
- Тема (light / dark / system), 6 акцентных цветов
- **Домашняя страница** — стартовая / пустая / свой URL
- **Кастомная тема из JSON** с валидацией значений
- **Кнопки тулбара** — вкл/выкл и порядок
- Папка загрузок, «спрашивать куда сохранять»
- Блокировка трекеров + статистика
- HTTPS-only режим
- Восстановление сессии
- Очистка кэша с индикатором размера

**Прочее**
- DuckDuckGo Autocomplete для подсказок в поиске
- Режим чтения (Reader Mode) на базе Mozilla Readability
- Поиск по странице (`Cmd/Ctrl+F`)
- Системное меню приложения с ролями
- Контекстное меню веб-страницы (ссылки, изображения, текст)
- **Drag & drop файлов** в окно (PDF → просмотрщик, остальные → системное приложение)
- 30+ горячих клавиш, работающих независимо от фокуса

- **Electron 44** — фреймворк (Chromium + Node.js)
- **electron-vite 5 + Vite 7** — сборка и dev-сервер

## 🚀 Быстрый старт

Требуется **Node.js 18+** и **npm**.

```bash
# Клонировать репозиторий
git clone https://github.com/StasAks1/Browser-school-project.git
cd Browser-school-project

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev
```

Для запуска с подробными логами используйте `DEBUG=1 npm run dev`.

Полная инструкция по установке, обновлению и удалению — см. [docs/INSTALLATION.md](docs/INSTALLATION.md).

## 🌍 Платформы

Проект **кроссплатформенный** — работает на macOS, Windows и Linux.

| Платформа | Как запускается | Особенности |
|---|---|---|
| **macOS** | `.dmg` | Светофоры по центру, `Cmd` вместо `Ctrl` |
| **Windows** | `.exe` (NSIS) | Нативные кнопки окна через `titleBarOverlay` |
| **Linux** | `.AppImage` / `.deb` | Системный заголовок окна, зависит от DE |

Один код — три платформы. Различия в поведении и детали реализации — см. [docs/CROSS-PLATFORM.md](docs/CROSS-PLATFORM.md).

## 🔒 Приватность

Браузер **не собирает персональные данные**:

- Нет телеметрии, аналитики, автоматических отчётов
- Cookie хранятся в изолированной сессии Chromium **только на устройстве пользователя**
- Закладки, история, настройки, загрузки — в локальной папке `userData`
- Разработчик не имеет доступа к данным пользователя
- Единственные внешние запросы — DuckDuckGo API (подсказки и favicons)
- «Недавно закрытые» вкладки хранятся **только в RAM** — при выходе стираются
- **Referrer обрезается до origin** — сайты не видят конкретную страницу, с которой пришёл пользователь
- **WebRTC ограничен публичным интерфейсом** — сайты не получают локальный IP
- **HTTPS-only режим** (опционально) — блокирует все HTTP-сайты
- Размер кэша Chromium **ограничен 100 МБ**, есть кнопка ручной очистки

Подробнее о соответствии 152-ФЗ и о том, какие данные где хранятся — см. [docs/PRIVACY.md](docs/PRIVACY.md).

## 📦 Сборка

### Локально

```bash
npm run dist:mac       # на macOS → .dmg в dist/
npm run dist:win       # на Windows → .exe в dist/
npm run dist:linux     # на Linux → .AppImage в dist/
```

Каждая команда требует соответствующей ОС.

### Через GitHub Actions

При пуше тега `v*` GitHub автоматически собирает установщики для всех трёх платформ и публикует их в [Releases](https://github.com/StasAks1/Browser-school-project/releases).

```bash
git tag v1.0.0
git push --tags
```

Через 10–15 минут в Releases появятся:

- `.dmg` и `.zip` (macOS)
- `.exe` (Windows: installer + portable)
- `.AppImage` и `.deb` (Linux)
