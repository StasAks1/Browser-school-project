# Browser Project

**Кроссплатформенный браузер на Electron** — итоговый проект по информатике, 10 класс.

Собственный Chrome UI в стиле Safari, вкладки, закладки с папками, история, загрузки, cookie-менеджер, приватный режим, режим чтения, блокировка трекеров. Все данные хранятся **только локально** на устройстве пользователя.

---

## ✨ Возможности

**Интерфейс**
- Chrome UI в стиле Safari с капсулой навигации `‹ ∣ ›`
- Адресная строка с автодетектом URL и поискового запроса
- Индикатор безопасности соединения (HTTPS / HTTP / внутренняя страница)
- Панель закладок с папками
- Status bar с URL при наведении на ссылку
- Светлая / тёмная / системная тема + 6 акцентных цветов
- Кастомные tooltips для иконок

**Вкладки**
- Создание, закрытие, восстановление закрытых (до 25), дублирование
- Favicon, заголовок, индикатор загрузки, плавные анимации
- Приватные вкладки (инкогнито) с отдельной сессией
- LRU-выгрузка неактивных вкладок для экономии памяти (макс. 10 одновременно)

**Данные**
- Закладки с папками, менеджер, импорт/экспорт в HTML (совместим с Chrome/Firefox)
- История с группировкой по датам, поиском, автоочисткой через 90 дней
- Загрузки с прогресс-баром, иконками по типу файла, счётчиком активных
- Cookie-менеджер: просмотр, создание, редактирование, удаление
- Восстановление сессии при перезапуске

**Безопасность и приватность**
- Кастомные диалоги разрешений (камера, микрофон, геолокация)
- Warning-страница для HTTP-сайтов
- Error-страница для сетевых ошибок и проблем с сертификатами
- Блокировка трекеров и рекламы (200+ доменов)
- Блокировка `file://` и `data:` в mainFrame
- CSP во всех внутренних HTML

**Прочее**
- DuckDuckGo Autocomplete для подсказок в поиске
- Режим чтения (Reader Mode) на базе Mozilla Readability
- Поиск по странице (`Cmd/Ctrl+F`)
- Системное меню приложения с ролями
- Контекстное меню веб-страницы (ссылки, изображения, текст)
- 20+ горячих клавиш, работающих независимо от фокуса

## 🛠 Стек

- **Electron 44** — фреймворк (Chromium + Node.js)
- **electron-vite 5 + Vite 7** — сборка и dev-сервер
- **JavaScript** (ESM в main, CJS в preload)
- **HTML + CSS** без фреймворков
- **@mozilla/readability** — движок Reader Mode

Подробнее о технологиях и зависимостях — см. [docs/TECHNOLOGIES.md](docs/TECHNOLOGIES.md).

## 🚀 Быстрый старт

Требуется **Node.js 18+** и **npm**.

```bash
# Клонировать репозиторий
git clone https://github.com/StasAks1/Browser-school-project.git
cd Browser-school-project

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev
```

Для запуска с подробными логами используйте `DEBUG=1 npm run dev`.

Полная инструкция по установке, обновлению и удалению — см. [docs/INSTALLATION.md](docs/INSTALLATION.md).

## 🌍 Платформы

Проект **кроссплатформенный** — работает на macOS, Windows и Linux.

| Платформа | Как запускается | Особенности |
|---|---|---|
| **macOS** | `.dmg` | Светофоры по центру, `Cmd` вместо `Ctrl` |
| **Windows** | `.exe` (NSIS) | Нативные кнопки окна через `titleBarOverlay` |
| **Linux** | `.AppImage` / `.deb` | Системный заголовок окна, зависит от DE |

Один код — три платформы. Различия в поведении и детали реализации — см. [docs/CROSS-PLATFORM.md](docs/CROSS-PLATFORM.md).

## 🔒 Приватность

Браузер **не собирает персональные данные**:

- Нет телеметрии, аналитики, автоматических отчётов
- Cookie хранятся в изолированной сессии Chromium **только на устройстве пользователя**
- Закладки, история, настройки, загрузки — в локальной папке `userData`
- Разработчик не имеет доступа к данным пользователя
- Единственные внешние запросы — DuckDuckGo API (подсказки и favicons)

Подробнее о соответствии 152-ФЗ и о том, какие данные где хранятся — см. [docs/PRIVACY.md](docs/PRIVACY.md).

## 📦 Сборка

### Локально

```bash
npm run dist:mac       # на macOS → .dmg в dist/
npm run dist:win       # на Windows → .exe в dist/
npm run dist:linux     # на Linux → .AppImage в dist/
```

Каждая команда требует соответствующей ОС.

### Через GitHub Actions

При пуше тега `v*` GitHub автоматически собирает установщики для всех трёх платформ и публикует их в [Releases](https://github.com/StasAks1/Browser-school-project/releases).

```bash
git tag v1.0.0
git push --tags
```

Через 10–15 минут в Releases появятся:

- `.dmg` и `.zip` (macOS)
- `.exe` (Windows: installer + portable)
- `.AppImage` и `.deb` (Linux)
