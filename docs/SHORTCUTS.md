# Горячие клавиши

Все комбинации работают **независимо от того, где находится фокус** — на панели браузера или на веб-странице. Модификатор: `Cmd` на macOS, `Ctrl` на Windows и Linux.

## Вкладки

| Действие | macOS | Windows / Linux |
|---|---|---|
| Новая вкладка | `Cmd+T` | `Ctrl+T` |
| Новая приватная вкладка | `Cmd+Shift+N` | `Ctrl+Shift+N` |
| Закрыть активную вкладку | `Cmd+W` | `Ctrl+W` |
| Восстановить закрытую | `Cmd+Shift+T` | `Ctrl+Shift+T` |
| **Переключиться на N-ную вкладку (1–9)** | `Cmd+1..9` | `Ctrl+1..9` |
| **Соседняя вкладка (влево/вправо)** | `Cmd+Opt+←/→` | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| Переставить вкладку (drag) | мышь | мышь |

## Контекстное меню вкладки (правый клик)

| Действие | Описание |
|---|---|
| Дублировать вкладку | Открывает копию текущей вкладки |
| Закрыть вкладку | Закрывает именно эту вкладку |
| Закрыть другие вкладки | Оставляет открытой только эту |
| Закрыть вкладки справа | Закрывает все вкладки после этой |

## Внутренние страницы

| Действие | macOS | Windows / Linux |
|---|---|---|
| История | `Cmd+Y` | `Ctrl+H` |
| Загрузки | `Cmd+J` | `Ctrl+J` |
| Настройки | `Cmd+,` | `Ctrl+,` |
| Управление расширениями | `internal://extensions` в адресной строке | то же |

> **Примечание для macOS:** `Cmd+H` зарезервирован системой под «Скрыть приложение», поэтому в браузере для истории используется `Cmd+Y`.

## Меню «История → Недавно закрытые»

Список последних 25 закрытых вкладок. Хранится **только в RAM**, при выходе стирается. Приватные вкладки в список не попадают.

## Блокировка рекламы и трекеров

Управляется через **Настройки → Приватность**. Хоткеев нет — только переключатели в UI:

- Глобальный вкл/выкл блокировки
- Каждая из **6 категорий** (реклама, аналитика, соцсети, маркетинг, фингерпринт, криптомайнеры) — отдельно
- URL-блокировка рекламы — отдельный переключатель

Индикатор счётчика блокировок виден в адресной строке (🛡 N).

## Расширения Chrome

Управление — на странице `internal://extensions`:

- **Установка** — ввести 32-символьный ID из Chrome Web Store
- **Удаление** — кнопка на карточке расширения
- **Обновление** — кнопка «Обновить все»

Быстрый доступ: **Настройки → Приватность → Управление расширениями**.

## Drag & drop

| Действие | Как |
|---|---|
| Переставить вкладку | Схватить вкладку за середину и тащить в нужное место |
| Переставить ярлык на стартовой | Схватить ярлык и тащить в нужное место |
| Открыть PDF в просмотрщике | Бросить `.pdf`-файл в любое место окна |
| Открыть любой файл системным приложением | Бросить файл в окно (не PDF) |

## Работа со ссылками и ярлыками

| Действие | Как |
|---|---|
| Открыть в текущей вкладке | Обычный клик |
| Открыть в новой вкладке (ярлыки на стартовой) | `Cmd/Ctrl+клик` или средняя кнопка мыши |
| Открыть закладку в новой вкладке | Средняя кнопка мыши на закладке |
| Меню действий ярлыка | Правый клик на ярлыке |
