# Горячие клавиши

Все комбинации работают **независимо от того, где находится фокус** — на панели браузера или на веб-странице. Модификатор: `Cmd` на macOS, `Ctrl` на Windows и Linux.

## Вкладки

| Действие | macOS | Windows / Linux |
|---|---|---|
| Новая вкладка | `Cmd+T` | `Ctrl+T` |
| Новая приватная вкладка | `Cmd+Shift+N` | `Ctrl+Shift+N` |
| Закрыть активную вкладку | `Cmd+W` | `Ctrl+W` |
| Восстановить закрытую (до 25) | `Cmd+Shift+T` | `Ctrl+Shift+T` |

## Навигация

| Действие | macOS | Windows / Linux |
|---|---|---|
| Фокус на адресную строку | `Cmd+L` | `Ctrl+L` |
| Назад | `Cmd+[` | `Ctrl+[` |
| Вперёд | `Cmd+]` | `Ctrl+]` |
| Домой | `Cmd+Shift+H` | `Ctrl+Shift+H` |
| Обновить | `Cmd+R` | `Ctrl+R` / `F5` |
| Обновить без кэша | `Cmd+Shift+R` | `Ctrl+Shift+R` |

## Закладки

| Действие | macOS | Windows / Linux |
|---|---|---|
| Добавить текущую страницу в закладки | `Cmd+D` | `Ctrl+D` |
| Открыть менеджер закладок | `Cmd+Shift+O` | `Ctrl+Shift+O` |

## Внутренние страницы

| Действие | macOS | Windows / Linux |
|---|---|---|
| История | `Cmd+Y` или `Ctrl+H` | `Ctrl+H` |
| Загрузки | `Cmd+J` | `Ctrl+J` |
| Настройки | `Cmd+,` | `Ctrl+,` |

## Поиск

| Действие | macOS | Windows / Linux |
|---|---|---|
| Поиск по странице | `Cmd+F` | `Ctrl+F` |
| Следующее совпадение | `Enter` | `Enter` |
| Предыдущее совпадение | `Shift+Enter` | `Shift+Enter` |
| Закрыть панель поиска | `Esc` | `Esc` |

## Масштаб

| Действие | macOS | Windows / Linux |
|---|---|---|
| Увеличить | `Cmd+=` | `Ctrl+=` |
| Уменьшить | `Cmd+-` | `Ctrl+-` |
| Сбросить до 100% | `Cmd+0` | `Ctrl+0` |

## Окно

| Действие | macOS | Windows / Linux |
|---|---|---|
| Полноэкранный режим | `Ctrl+Cmd+F` | `F11` |
| Скрыть приложение | `Cmd+H` | — |
| Свернуть окно | `Cmd+M` | — |
| Выход | `Cmd+Q` | `Ctrl+Q` |
| Открыть системное меню | — | `Alt` |

## Режим чтения

| Действие | macOS | Windows / Linux |
|---|---|---|
| Включить/выключить Reader Mode | `Cmd+Shift+E` | `Ctrl+Shift+E` |

## Разработка

| Действие | macOS | Windows / Linux |
|---|---|---|
| DevTools текущей вкладки | `Alt+Cmd+I` | `Ctrl+Shift+I` |
| DevTools панели браузера | `Alt+Cmd+Shift+I` | `Ctrl+Shift+Alt+I` |
