Расширения

Расширения устанавливаются из официального Chrome Web Store. Браузер работает с расширениями на Manifest V3 (например, uBlock Origin Lite).

Расширения — это сторонний код. Они могут получать доступ к содержимому страниц, вашим действиям и передавать данные их авторам. Устанавливайте только те расширения, которым доверяете. Разработчик браузера не контролирует и не несёт ответственности за действия установленных расширений.
ID — это 32-символьный код в адресе расширения на chromewebstore.google.com. Например, для uBlock Origin Lite: ddkjiahejlhfcafbddmgiahcphecmpfh
